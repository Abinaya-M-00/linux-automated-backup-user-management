# Linux Automated Backup and User Management Project

## 📌 Project Overview

This project demonstrates Linux system administration tasks and an automated backup system using Shell Scripting and Cron.

## 🚀 Features

- 👤 Create and manage Linux users
- 👥 Create Linux groups
- 🔐 Configure file and directory permissions
- 📁 Create important directories
- 💾 Automate backups using Shell Script
- 📝 Create backup logs
- ⏰ Schedule automated backups using Crontab

## 🛠️ Technologies Used

- Linux
- Bash / Shell Scripting
- Cron
- File Permissions
- User and Group Management
